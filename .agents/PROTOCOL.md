# Протокол работы

Общие инструкции находятся в [AGENTS.md](../AGENTS.md).

1. Перед изменениями прочитать `AGENTS.md`, `.agents/STATE.md` и `.agents/HANDOFF.md`.
2. Определить границы задачи и связанные требования из `docs/TRACEABILITY.md`.
3. Выполнить изменения, не затрагивая чужую работу и исходные материалы.
4. Запустить подходящие проверки. Для каркаса репозитория — `make check`.
5. Обновить `.agents/STATE.md`; при передаче работы заполнить `.agents/HANDOFF.md`.
6. Записать результаты ревью в соответствующий файл `.agents/reviews/M*.md`.

Неизвестные требования отмечать как `TBD`. Блокеры записывать с причиной и следующим действием.
Распределение работы между несколькими агентами выполнять по явному запросу пользователя.

## Контрольные точки

Ниже предложен порядок ревью; его нужно сверить с официальным заданием.

| Ревью | Предмет |
| --- | --- |
| M1 | Требования и трассируемость |
| M2 | Архитектура и интерфейсы |
| M3 | Реализация и проверки |
| M4 | Метрики и демонстрация |
