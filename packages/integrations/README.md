# Integrations

Назначение: webhook, CRM, GVERA.

Статус: каркас. Контракты, способы авторизации, обработка ошибок
и требования конкретных интеграций пока не определены.
Секреты хранить в локальном окружении, примеры переменных — в `.env.example`.

Примечание (M1): исходящий `send_webhook` был удалён (M1-011/M1-012) —
защита соединения доставки от DNS-rebinding без рискованного custom
DNS/TLS egress-транспорта невозможна. В M1 выполняется только локальное
действие `create_notification`. Интеграция с проверенным egress отложена.
