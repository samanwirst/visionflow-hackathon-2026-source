# Three-minute technical defence notes

These statements follow executed evidence. Do not extend them to untested
cameras, weather, prices or an unaccepted release. The jury may ask any team
member about assistant-written code.

| Topic | Precise explanation |
| --- | --- |
| End-to-end product | Upload a supported MP4, define a polygon and explicit geometric rule, review server-validated JSON, approve, then run. YOLO11n plus ByteTrack produces real events with JPEG evidence and a durable local notification. Editing/disabling/re-enabling is shown in the actual recording. |
| OpenVector-inspired architecture | Cheap detection, tracking and temporal logic decide when expensive reasoning could be useful. Selective routing, deduplication, caching and call budgets are architecture requirements. Geometric rules make zero Teacher calls. M2 is BLOCKED, so its NL/Teacher action paths remain disabled. |
| Genuine Teacher inference | A pinned SmolVLM-500M model actually processes images on the local RTX3050. Raw generated JSON failed validation; the disclosed alternative scores two complete candidate-label sequences with image-conditioned model forwards and serializes scores as JSON. It is not successful JSON generation or calibrated confidence. |
| Human verification | The user inspected the exact 24-image contact sheet. Teacher proposed occupied for all images; twelve empty labels were corrected. The user's approval covers those image hashes and synthetic ground truth, not Teacher quality or model activation. |
| Real Student training | Frozen pretrained ResNet18 yields 512 features; a small logistic head is genuinely fitted, saved and reloaded. The training set has 14 images, validation 4 and test 6, grouped by rendering session. The split amendment was registered before fitting; thresholds use validation, not test outcomes. |
| Quality and timing | On six unique synthetic held-out images, Student was correct 6/6 and Teacher 3/6. Eighteen repeated timing observations do not enlarge quality support. Mean warm wall latency was 40.189ms for CPU encoder+Student versus 432.792ms for local GPU Teacher HTTP calls, under shared-host load. These belong to experimental snapshot5938b6d, whose QA required changes. |
| GPU time and cost | A separate direct-model profiler measured mean summed CUDA kernel duration86.388ms on the same six hashes, with overhead. This is not GPU allocation time or paid billing time. Vast was destroyed before remote inference; rounded disk charge$0.001, finalized invoice unverified. Cost/event, ROI and percentage savings are not measured. |
| Foveation and research | Full-frame, high-resolution ROI and foveated ROI-with-scene-context are planned comparisons on identical held-out events. A crop discards context; foveation retains it at lower resolution. The CVPR paper's gains are not VisionFlow results, and fewer pixels do not imply linear billed-cost reduction. |
| Gates and limits | Final experimental code passed249 tests/build/realYOLO but independent review returned CHANGES_REQUIRED with6P1. AutoLearn is not integrated or accepted, and no Student is active. Shadow dispatched no actions. Real-model activation/rollback, natural-video quality and public reachability are unverified. Private authentication/deployment and the geometric fallback are demonstrated. |
| Business case | The intended customer is a service-centre manager. Site/camera subscription pricing and willingness to pay are hypotheses for a supervised pilot. ROI needs actual operator time saved, hourly cost and measured system expense; no invented payback. |
