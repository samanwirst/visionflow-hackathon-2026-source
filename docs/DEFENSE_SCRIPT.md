# Seven-minute defence — VisionFlow AI

Mode: **Startup**. User: the manager of an automotive service centre.
The accepted geometric workflow is the dependable live demo. AutoLearn is an
isolated experiment; describe only results in its final executed evidence report.
Never substitute a research-paper gain or an infrastructure estimate for a
VisionFlow measurement.
